# 小白使用指南（不用敲命令）

> 这份指南假设你**没写过代码**。全程只需要：双击一个文件、在网页里点几下。

---

## 一、准备

| 准备项 | 说明 |
| --- | --- |
| 一台 Windows 电脑 | 也可以用 Mac/Linux；正式 24 小时接待建议放服务器，见 [部署指南](deployment.md) |
| Python 3.10+ | Windows 安装时**务必勾选 “Add Python to PATH”**：[下载](https://www.python.org/downloads/) |
| Chrome 浏览器 | 扫码登录拼多多商家后台时用 |
| 拼多多商家账号 | 能登录商家后台、有客服权限的账号即可 |

---

## 二、启动（只需一次）

1. 在 GitHub 页面点 **Code → Download ZIP**，解压到任意目录（不要放在 C 盘根目录）；
2. 双击 **`start.bat`**；
3. 第一次会自动安装依赖、生成配置（约 1–2 分钟，黑窗口别关）；
4. 浏览器会自动打开面板：`http://127.0.0.1:38617`。

> 如果没自动打开浏览器，手动复制黑窗口里显示的地址。
> macOS / Linux 用户：在项目目录执行 `bash start.sh`。

---

## 三、在网页里登录店铺

1. 打开面板后，点顶部 **「店铺与登录」**；
2. 找到你的店铺卡片，点 **「扫码登录」**：
   - 会弹出一个独立的 Chrome 窗口；
   - 用手机扫码（或账号密码）登录拼多多商家后台；
   - 登录成功后浏览器自动关闭，面板显示「在线接待」。
3. 没有桌面浏览器（例如服务器）？点 **「粘贴 Cookie」**：
   - 在已登录拼多多商家后台的浏览器按 `F12` → `Network` → 随便点一个请求 → 复制请求头里的 `Cookie` 整行；
   - 粘贴进面板，点保存即可。

多个店铺：先在「添加店铺」里填店铺 ID（例如 `shop-a`）和名称，然后逐个登录。
登录态过期也没关系，面板会提示，重新扫码即可，不用重开程序。

### 服务器不用装 Chrome：本机登录 → 服务器导入

如果程序跑在 Linux 服务器上（没有桌面），按这 3 步把本机登录态搬过去：

1. 在**你自己的电脑**打开本地面板 → 「店铺与登录」→ 点「扫码登录」（或粘贴 Cookie）；
2. 登录成功后，点店铺卡片上的 **「导出登录态」** → 复制登录码（或下载 JSON 文件）；
3. 打开**服务器面板** → 同一店铺点 **「导入登录态」** → 粘贴登录码/上传文件 → 完成。

服务器全程不需要安装 Chrome；导入后几秒内自动上线。登录码等同于账号密码，请只在自己的
设备间传输，导入完成后建议删除导出的文件。

**如果服务器本身有桌面/RDP**：也可以在服务器上直接安装 Chrome——面板「店铺与登录 → 运行环境」
会显示检测结果，点「一键下载 Chrome」即可（或运行 `python -m pdd_cs chrome --install`），
装好后就能在面板里扫码登录。注意：Linux 服务器如果没有图形界面，装了 Chrome 也无法弹窗扫码，
仍然用上面的「导出 → 导入」方式最稳。

## 三·补充、服务器公网访问时先登录

如果项目部署在服务器上并通过公网地址访问，打开网址会先看到一个登录页：

1. 输入**访问令牌**（管理员在服务器 `/etc/pdd-cs.env` 或 `/opt/pdd-cs/access-credentials.txt` 里查看）；
2. 点「进入控制台」；
3. 右上角「退出」可以安全退出。

令牌等同于面板密码，请不要发到群里；登录失败次数过多会短暂限制尝试。

## 四、在网页里做设置

点顶部 **「系统设置」**，改完点 **「保存并生效」**（会自动重连店铺，约 3–10 秒）：

| 设置区 | 作用 |
| --- | --- |
| AI 回复设置 | 填大模型接口地址、模型名、API Key；可点「测试 AI 连接」验证。**不填也能用**，只是只用关键词回复 |
| 回复规则 | 默认回复、没答案时转人工/默认回复、回复延迟、人工接管时长 |
| 营业时间 | 下班后自动改用另一套话术 |
| 告警通知 | 填钉钉/飞书/企业微信机器人 Webhook，掉线、登录过期会推送到群；可「发送测试告警」 |
| 面板与安全 | 端口、访问令牌（服务器用；改完需重启程序生效） |

---

## 五、在网页里改话术和知识库

点顶部 **「话术与知识库」**：

- **关键词话术**：命中关键词自动回复；可直接在表格里改、加、删，点「保存话术」立即生效；
- **店铺知识库**：AI 回答会参考的内容，Markdown 写，点文件即可编辑；
- **店主 / 客服人设**：影响 AI 说话风格；
- 保存后会显示平台规则检查结果，有风险会提示。

---

## 六、日常看数据

顶部 **「运营概览」** 就是首页：

- 今日进线、自动回复、转人工、首响达标率、待处理；
- 会话监控：点客户一行可以看完整聊天记录；
- 待处理队列、风控与合规事件、运营洞察、会话质检；
- 决策测试台：输入一句话试运行，不会真的发给客户。

程序挂着就行，面板每 5 秒自动刷新。需要 24 小时接待时把程序放服务器，见 [部署指南](deployment.md)。

## 七、常见问题

| 现象 | 解决 |
| --- | --- |
| 双击 start.bat 一闪而过 | 没装 Python 或没勾选 PATH；重装 Python 时勾选 “Add Python to PATH” |
| 安装依赖很慢/失败 | 脚本会自动切换国内镜像；仍失败可检查网络/代理 |
| 浏览器没自动打开 | 手动访问黑窗口里的地址；被安全软件拦截就允许一下 |
| 点「扫码登录」没反应 | 没装 Chrome，或服务器没有桌面；用本机登录后「导出登录态」，再到服务器「导入登录态」（或粘贴 Cookie） |
| 没有 Chrome 能运行吗 | 能。程序运行、自动回复、设置都不需要 Chrome；面板「运行环境」可一键下载 Chrome，也可以用粘贴 Cookie/导出导入 |
| 服务器有 Chrome 能直接扫码吗 | Windows 桌面/RDP 服务器可以；Linux 无图形界面（DISPLAY）时即使装了 Chrome 也无法弹窗，请用本机登录→导出→导入 |
| 电脑/服务器内存要求 | 服务进程实测 1 店约 40 MB、5 店约 42 MB，512 MB 内存足够；扫码登录时 Chrome 会临时占 300–500 MB，登录完关闭 |
| 扫码后一直显示「等待扫码」 | 确认登录的是 `mms.pinduoduo.com` 商家后台；超过 10 分钟会自动超时，重试即可 |
| 面板提示店铺掉线/登录过期 | 到「店铺与登录」重新「扫码登录」或「粘贴 Cookie」 |
| 保存设置后没变化 | 确认点了「保存并生效」；端口/令牌类设置需重启程序 |
| 中文显示乱码 | 用新版 Windows Terminal / 新版 Chrome；一般不影响使用 |
| 想改端口 | 「系统设置 → 面板与安全」改端口，重启程序；也可用环境变量 `PDD_CS_PORT` |
| 电脑关机了怎么办 | 关机后程序停止，客户消息不会自动回复；正式使用请部署到服务器 |

## 八、高级用法（可选，不看也行）

如果你愿意用命令行，也可以：

```bash
python -m pdd_cs setup      # 交互式向导
python -m pdd_cs login      # 终端扫码登录
python -m pdd_cs doctor     # 环境自检
python -m pdd_cs run        # 启动
python scripts/demo.py      # 没有店铺时看演示
```

更多说明见 [README](../README.md)、[运营手册](operations.md)、[部署与掉线通知](deployment.md)。
