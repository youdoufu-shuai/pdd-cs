# 尺码咨询（通用说明）

默认配置不提供任何店铺或商品的具体尺码、测量值和尺码图片。实际商品尺码以该商品详情页为准。

## 回复口径

- 先确认商品、款式和规格，再参考对应商品的尺码表。不同商品及男女款的尺码表不能混用。
- 不确定尺寸或客户处于两个尺码之间时，转人工按商品尺码表确认；不要统一建议拍大一码。
- 不承诺「肯定合身」或「不合适包退」。

## 店铺配置

在私有部署的商品资料库中填写经核对的测量值和款式对应关系。需要自动发送图片时，可在本地关键词规则中设置 `reply_type: image`，填写平台允许使用的本店尺码图地址及可选文字说明。不要把店铺资料或链接提交到公共仓库。
