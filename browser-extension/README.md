# PDD 客服面板快捷入口

这是可选的 Chrome / Edge 面板书签。它没有后台任务、商家页脚本或主机访问权限，不读取店铺 Cookie 或访问令牌，也不自动发送登录态。没有内置面板地址。

## 安装

1. 从仓库下载 `browser-extension.zip`，解压到独立目录。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启开发者模式并「加载已解压的扩展程序」。
3. 点击扩展，填写你自己的面板网址并点「打开面板」。远程面板须用 HTTPS；本机面板或 SSH 隧道的入口可用 `http://127.0.0.1:38617/`。不要把令牌、账号或密码写入网址。
4. 扩展只在本机保存这个网址；点「清除地址」可删除。之后请在面板中登录。

## 从旧登录同步扩展迁移

- 先从 Chrome / Edge 的扩展管理页面**移除旧的「PDD 客服登录同步」扩展**，再安装此版本。GitHub 上更新 ZIP 不会自动卸载已安装的旧扩展。
- 新版本不再导入登录态或截取商品卡片签名。请在面板「店铺与登录」里使用扫码等现有登录方式；如面板只监听服务器本机，先按部署文档建立 SSH 隧道，再在本机打开。请勿把登录材料发给不明地址。
- 若曾把登录态或面板令牌提交给不受你控制的服务器，请重新登录店铺以更新会话，并轮换受影响的面板令牌。

维护者可在仓库根目录运行 `python3 scripts/package-browser-extension.py` 重建 ZIP，或加 `--check` 核验发布包与源文件一致。
