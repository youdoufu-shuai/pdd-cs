# 店铺政策（示例，请按自己店铺的实际情况修改）

> 重要：自动回复里提到的发货时效、快递、退换货、运费险等口径，必须与商品详情页 /
> 店铺公告公示的内容完全一致。口径不一致时，风险不在「回得慢」，而在「回错了」。
> 下面方括号里的内容需要你替换成自己店铺的真实政策。

## 发货时效

- 本店默认发货时效：【48 小时内发货】（以商品详情页公示为准）。
- 预售商品按详情页标注的预售时间发货。
- 客户问「什么时候发货」时，回答口径：发货时效以商品详情页公示为准；下单后可在订单页查看物流进度。
- 不要回答具体日期或「今天一定发」，也不要承诺「明天到」。

## 快递

- 本店默认快递：【中通 / 圆通 / 韵达 / 极兔】，偏远地区可能转邮政。
- 客户指定快递：以仓库实际发运为准，不承诺指定快递一定满足；如有特殊需求，转人工备注。
- 客户问「发什么快递」时，回答默认快递 + 「以实际发运为准」。

## 运费险

- 本店【有 / 没有】运费险。
- 只能回答「本店本商品有没有运费险」，理赔条件与赔付结果以平台页面和保险方为准，客服不做承诺。

## 退换货

- 支持 7 天无理由退换货（商品需不影响二次销售，以平台规则为准）。
- 退换货流程：客户在订单页发起申请 → 按平台提示寄回 → 商家验收后退款。
- 客服不承诺「肯定能退」「包退」，统一口径：售后按平台页面流程处理。
- 质量问题 / 少发 / 错发 / 破损：请客户提供商品照片与订单号，转人工核实处理。

## 发票

- 本店【支持 / 不支持】开具电子普通发票。
- 需要发票请提供：订单号、发票抬头、税号（企业）、接收邮箱。
- 开票信息核对与开票时效需要人工处理，统一转人工。

## 售后处理时效

- 客户提交售后申请后，本店在【24 小时】内处理（以平台页面显示为准）。
- 客户催促售后：说明已收到申请、会尽快处理，必要时转人工。

## 营业时间

- 人工客服在线时间：【08:30 ~ 22:30】。
- 非工作时间由智能客服先接待，人工上线后跟进。
