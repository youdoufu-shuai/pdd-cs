登录方式说明

方式一：扫码登录（推荐）
有桌面的电脑会弹出 Chrome 窗口扫码；服务器没有桌面时，点「服务器扫码登录」会把二维码显示在页面里。

方式二：粘贴 Cookie / cURL
在已登录拼多多商家后台的浏览器按 F12 → Network → 任意请求 → 复制请求头里的 Cookie 整行；也可以右键请求 → Copy as cURL，整段粘贴进来。

登录态过期怎么办？
面板提示掉线或登录过期时，重新扫码登录即可，不需要重开程序。

提示店铺不匹配？
说明这份登录态属于另一个拼多多店铺，系统会拒绝保存；请确认浏览器右上角店铺后再复制。

服务器扫码 / 登录态导入

二选一
服务器已安装 Chrome：直接点店铺卡片「服务器扫码登录」，二维码会显示在弹窗里。

也可以用登录态迁移：
  1. 在你自己的电脑登录拼多多商家后台，点「导出登录态」；
  2. 在服务器面板同一店铺点「导入登录态」，粘贴登录码或上传文件。
登录态等同于账号密码，请只在自己的设备间传输，导入后删除导出文件。

客服权限（必须）

没有它收不到客户消息
拼多多只把客户消息推送给「有客服权限且在线」的账号。如果运行状态显示 「已连接 · 待授权」或接口返回「没有聊天权限」，按下面检查：
  1. 添加客服：商家后台 → 多多客服 → 客服工具 → 多客服管理 → 添加客服，输入要用的拼多多账号；
  2. 子账号权限：或用「店铺管理 → 子账号管理」给账号勾选「客服」权限；
  3. 分流设置：多多客服 → 客服工具 → 分流设置，确认该账号不在「不分流」名单；
  4. 在线状态：多多客服 → 在线状态，确认账号在线；
  5. 重新登录：用这个有客服权限的账号重新扫码/导入登录态，刷新面板应显示「在线接待」。
主账号不一定自动拥有客服权限；最稳的方式是新建一个客服子账号来登录。
打开拼多多子账号管理 打开客服分流设置
创建客服子账号时，拼多多会向主账号绑定手机发送短信验证码；这一步只能由你本人完成。
